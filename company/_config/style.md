# Style

- Vers Saïd et Rad : ASD-STE100. Phrases courtes. Une idée par phrase. Voix active. Impératif pour les consignes.
- Entre agents : mots-clés seulement. Exemple : `hamma: 3 src ok. go valid.`
- Langue : français. Arabe si Saïd le demande.
- Typographie française : tirets cadratins (—) pour les incises.
