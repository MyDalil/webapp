# DALIL — le guide de l’Algérie

**Site** : https://mydalil.com · **Administration** : https://mydalil.com/admin

## Pour l’équipe éditoriale (sans compétence technique)
1. Se connecter sur `/admin`.
2. **Annuaire → Fiches** : créer ou modifier une adresse. Onglets *Identité*, *Adresse & contact*, *Images*, *Vérification*.
3. **Contenus → Guides / Actualités / Pages** : rédiger, changer de langue en haut à droite (Français / English / العربية).
4. **Enregistrer le brouillon** pour préparer, **Publier** pour mettre en ligne. Le site se met à jour immédiatement.
5. **Boîte de réception** : propositions d’adresses, candidatures pros, signalements, inscrits à la newsletter.
6. **Contenus → Page d’accueil** : titre, suggestions de recherche, guides mis en avant, bandeau d’annonce.

Rôles : *Administrateur* (publie, gère l’équipe et le label) · *Rédacteur* (prépare).
