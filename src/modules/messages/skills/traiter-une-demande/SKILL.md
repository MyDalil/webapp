# Traiter une demande de la boîte de réception DALIL (contribution, candidature, contact)

1. /admin → Boîte de réception → Demandes, filtrer sur « Nouveau ».
2. Passer en « En cours » : le demandeur est prévenu automatiquement.
3. Contribution d’adresse : créer ou corriger la fiche dans `annuaire`, statut de vérification honnête.
4. S’il manque une information : « Infos manquantes » + message au demandeur (obligatoire).
5. Clore : « Traité » ou « Refusé » (message obligatoire si refus). Chaque passage envoie un email.
6. Note interne pour l’équipe ; jamais d’information personnelle dans les fiches publiques.
